How it works
1
Set up the laptop
Log in to get a permanent room code. Install the Chrome extension and enter the code once.
2
Connect a phone
Scan the QR or open mobile.html and type the room code. Multiple phones can join.
3
Scan the form
Tap Take Photo and photograph the paper intake form. AI reads the handwriting instantly.
4
Review & confirm
Check every extracted field on the phone, fix any mistakes, then tap Confirm & Fill Form.
5
Form fills itself
The NCNMO web form on the laptop fills in automatically — name, gender, date of birth, everything.
6
Next patient, instantly
Laptop loads a fresh blank form. Scan the next patient's form and the cycle repeats.
Chrome Extension Setup
⇓ Download Extension (.zip)
  1. Download and unzip the file above
  2. Go to chrome://extensions in Chrome
  3. Enable Developer mode (top-right toggle)
  4. Click Load unpacked → select the unzipped folder
  5. Click the extension icon → enter room code —
  6. Click a scan below → then hit Fill Page Now in the extension
