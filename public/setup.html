⚙️ Scan to Fill — Setup

Configure once, scan forever.

💡

How it works: OCR reads your paper form as raw text. A regex pattern (with one capture group) extracts the value. A CSS selector tells the browser extension which form field to fill on your website.

Target Website

The website URL where you want forms auto-filled.

Field Mappings

Map each paper field → how to extract it from OCR text → which input to fill on the website. Right-click an input on your target site and choose "Inspect" to find its CSS selector.

Field Name Regex Pattern (group 1 = value) CSS Selector (on target site)

Examples

Field Name Regex Pattern CSS Selector
Full Name Name:\s*(.+) #fullName
Date of Birth DOB:\s*(\d{2}\/\d{2}\/\d{4}) input[name="dob"]
Email ([\w.+\-]+@[\w\-]+\.\w+) input[type="email"]
Phone Phone:\s*([\d\s\-().+]+) input[name="phone"]
